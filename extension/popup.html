    Downloads

    Photos and videos are saved to Downloads/KeepKeep.

    Chrome asks where to save each file So albums are saved as one ZIP for now: one window per post instead of one per photo. Turn off “Ask where to save each file before downloading” and everything is saved straight away, with no window.

    To save somewhere else, change the download location in Chrome's settings.
